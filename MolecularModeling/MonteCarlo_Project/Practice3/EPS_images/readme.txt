Instructions:
To run the code, upack all files into the same directory. Then,simply load the 
MisztalMurphyJorgepractice3.ipynb file in a jupyter kernel. The seed (42) is 
predefined in the code.

Plots will be saved as images in the same directory.

Runtime should be about an hour, give or take, depending on the system hardware.

Python package requirements:

  - NumPy
